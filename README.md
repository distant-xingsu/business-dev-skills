# Business Dev Skills · 后台管理系统开发技能集

面向 PC 后台管理系统的四个中文开发技能，覆盖界面设计、业务接口、权限流程及可视化编辑器。适用于运营管理、内容管理、订单管理、资产设备管理、组织权限、审批和配置管理等业务场景，支持新建功能、维护现有页面和修复操作流程。

技能提供可执行的设计、实现与核验指导，不包含现成后台模板或业务服务。沿用目标项目的框架、组件库和业务契约；Vue 与 Element 示例按技术栈选用。每个技能目录可单独使用，跨职责任务再组合。

## 本地使用

例如：`$dev-pc-product-ui-design 调整后台商品编辑弹窗。保留控件默认尺寸，修正标签对齐、字段宽度和提示出现后的留白。`

将所需的完整技能目录从 `skills/` 复制到本机技能目录（例如 `~/.codex/skills/`），保留目录名及其内部结构。升级前备份已有自定义修改，按相同标识更新，避免保留多份重复技能。

## 功能覆盖

### 后台管理界面设计

- 布局与列表：导航与页面分区、筛选查询、表格分页、行操作、列表详情联动、宽度分配与独立滚动。
- 表单与弹层：标签对齐、字段宽度、错误定位、只读信息、独立编辑草稿、键盘焦点及未保存退出保护。
- 按钮与反馈：动作主次、语义图标、主题颜色、保存与提交文案、按需帮助、Alert 留白及加载/空态/错误态。
- 组件复用与迁移：核对布局插槽和组件契约，对照设计稿保留真实操作顺序，提供按需迁移的文件与适配清单。

紧凑通过减少多余 padding、margin 和 gap 实现，保留正常控件尺寸。常用按钮优先采用语义图标与文字；使用 Iconify 时可选择 Carbon，并沿用项目已有封装和主题。

### 业务接口联调

- 核对字段、枚举、空值、日期精度、错误响应和分页契约。
- 区分输入草稿与已提交查询条件，处理重复请求、对象切换及迟到响应。
- 检查搜索范围、候选截断、关联查询与真实总数，避免漏查或错误提示全部结果。
- 区分保存、流程提交与刷新结果；核对保存回读、超时未知结果、幂等键和版本。

### 业务权限与流程

- 对齐菜单、路由、按钮、搜索、快捷入口与服务端鉴权。
- 核对角色、组织、租户、归属及记录范围；区分可发现、可查看和可操作。
- 梳理审批、撤回、作废和归属变更的前置条件、状态转换与必要副作用。
- 验证允许与相邻拒绝路径，处理重复或并发操作；代码修改与实际账号授权分别管理。

### 编辑器状态与操作

- 明确文档、选择集合、属性面板、视口与临时交互的状态所有权。
- 管理选中、多选混合值、拖拽、批量修改、撤销重做及快捷键边界。
- 对齐尺寸、换行、选中框和预览结果，接入组件、素材及稳定类型标识。
- 管理保存快照、未保存状态、恢复冲突、对象引用和资源释放。

仅在后台包含设计器或可视化配置能力时使用编辑器技能；普通数据表单使用界面与接口技能。

## 使用边界

按已确认需求选择功能，不默认给项目增加所有能力。界面调整保留字段、权限和操作语义；真实接口未接、失败与空数据分别表达。验证按变更选择界面、接口、权限或状态证据，不把模拟成功当作真实接通，也不把检查命令固定串成全套流程。

## 从问题选择技能

| 例子 | 从哪里开始 | 判断完成的依据 |
| --- | --- | --- |
| 搜索栏占了半屏，日期和按钮挤在一起 | 后台管理界面设计 | 同一窗口下控件对齐，查询行为保持原样 |
| 修改条件再翻页，结果混入未提交的条件 | 业务接口联调 | 翻页沿用已提交条件，迟到响应不覆盖新结果 |
| 搜索能找到记录，但详情入口与岗位范围不一致 | 业务权限与流程；若查询截断再结合接口联调 | 合法入口能用，直接访问越界对象被拒绝 |
| 保存过程中继续移动节点，界面却显示全部已保存 | 编辑器状态与操作；若需核对后台版本再结合接口联调 | 只确认提交时的快照，新移动仍标为未保存 |
