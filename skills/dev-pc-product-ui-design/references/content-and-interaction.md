# 内容与操作布局

用于本次涉及的表单、内容尺寸、滚动或拖拽问题；不作为所有页面的固定验收套餐。

## 表单与空间

- 以目标项目已认可的同类表单为基准，核对标签位置与宽度、必填标记、控件外框、字段内容和操作区的对齐。不要只比较 CSS 数值，输入、选择、日期等组件的内部结构可能不同。
- 同组同用途字段保持一致宽度，按内容用途分配空间；短编码、数量不必占满整行，长名称和说明可独占一行。多列布局保留阅读顺序，不把所有字段等分或强制采用固定像素宽度。
- 校验错误、帮助文字和多行标签出现时不能压住下一字段或造成同行错位。优先现有表单布局能力，不给所有字段永久塞一大块空白。
- 间距由明确的一层负责：页面边缘、区块之间、字段之间分别核对，消除重复 padding/margin；同层统一但不全部归零。紧凑减少无用空间，保留控件默认尺寸和必要分组。

## 按任务与内容选择布局

选择与详情需连续对照时考虑左右联动；多条同结构数据需比较时考虑表格；有明确步骤或纵向阅读顺序时保留上下结构。左右布局不是全局偏好，先核对内容宽度、字段数量、主次关系和项目约定。

涉及容器布局时选择实际相关的空、单条、多条或长内容检查，不只用最短样例设计首屏。宽屏空白先看是否容器限宽或分配不合理，不为填满空间添加卡片和说明。

## 文字尺寸与溢出

明确内容自适应与固定宽高的语义，再决定换行、省略、滚动或完整查看入口。检查本次相关的长中文、连续编码、多行文本和带单位数值；关键动作、错误信息和编辑控件不能被直接截断。

换行需要可用宽度和可增长高度；省略需要可访问的完整内容。不能用 overflow:hidden 或缩小字号掩盖尺寸错误。画布文字、选中框与预览尺寸不一致时转入编辑器状态与渲染链诊断，不当成普通表格 tooltip 问题。

## 滚动与拖拽

- 每个面板明确滚动所有者。内部长内容到边缘时，按任务判断是否阻止滚动传递，避免意外带动外页；不全局禁用滚轮或破坏正常导航。
- 可调整大小的 JSON/代码面板明确手柄、最小/最大尺寸与可用空间；拖动过程中及结束后核对滚动、选择文本和手柄可达性，不能只看静止截图。
- 树排序或画布拖动到边缘时，沿用既有自动滚动或移动视口机制；没有该能力时先判断是否本次必要，不顺带引入拖拽框架。

## 返工与交付前自查

对本批修改主动核对实际外框、字段对齐、提示出现后的留白、溢出和操作可达性，只选受影响部分。用户反馈“还是有问题”时回到同一对象、内容与操作状态，说明上次遗漏了哪个条件；沿尺寸或状态链定位，不叠加无依据的 margin、固定高度和裁剪补丁。

涉及动态行为时核对开始、过程中和结束后的相关状态。报告检查覆盖的载体与内容；一张静态截图不证明拖拽正常，一种模板通过不代表所有模板通过。已有适用证据复用，不扩成全项目复验。
